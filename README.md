# Hibernate Note Taker

A CRUD web application built using Java, Hibernate ORM, JSP, Servlets, MySQL and Bootstrap.

## Features
- Add Notes
- View Notes
- Update Notes
- Delete Notes

## Technologies Used
- Java
- Hibernate
- JSP & Servlet
- MySQL
- Bootstrap 5
- Maven
- Apache Tomcat

## Database
MySQL
